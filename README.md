# Humm — public demo

This is the public https demo of Humm, a browser speech-rehabilitation
prototype: `index.html` is a single self-contained file (face tracking, audio,
and all assets embedded) generated by `npm run build` from the same source as
the clinical `file://` deliverable, and it makes no network requests of its
own — all camera and microphone processing stays on your device, and nothing
is recorded or uploaded. It exists so the app can be tried over https (for
example on a phone, where https also lets the browser remember the camera
permission between visits); open `index.html` via GitHub Pages, tap Start, and
allow the camera and microphone when asked.
